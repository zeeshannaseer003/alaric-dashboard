# Alaric Dashboard

Self-contained prototype of the **Alaric** medical billing / coding support platform.

## Features

- **3 roles** (switchable in the sidebar):
  - **Member** (provider) – submit requests, view own answers, hire requests, resources, verification status
  - **Staff** – assigned requests + permission view
  - **Admin** – full overview, assign requests, verify members, manage roles/permissions, privacy & security settings

- Privacy-first design: no chat, no member directory. Users only see their own records or assigned work.

- Fully client-side (vanilla HTML/CSS/JS). No backend required for the demo.

## How to run

Just open `index.html` in any modern browser.

Or enable GitHub Pages and visit the live demo.

## Demo data

Includes sample members, requests, answers, and verification records so you can explore every screen immediately.
